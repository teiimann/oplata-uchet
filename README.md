# Оплата

Мобильный статический сайт для учёта ежемесячных начислений и оплат. Без сборки и сторонних библиотек.

## Модель

- **Плательщик** — компания или ИП, контакт и состояние (активен/архив).
- **Ежемесячный счёт** — объект или услуга, номер договора, текущая сумма. У плательщика может быть несколько счетов.
- **Начисление** — копия суммы счёта за конкретный месяц. Изменение текущей суммы не меняет историю.
- **Оплата** — отдельное поступление по начислению. Допускаются частичные оплаты. Остаток вычисляется автоматически.

Первый экран показывает сумму начислений, поступлений и остаток за выбранный месяц. Раздел «История» суммирует все созданные начисления. JSON служит полной резервной копией; CSV открывается в Excel.

## Запуск и GitHub Pages

Опубликуйте **содержимое этой папки** (`index.html`, `styles.css`, `app.js`) в корне репозитория или настройте GitHub Pages на соответствующую папку. Сборка не нужна. Для локального просмотра откройте `index.html` или запустите обычный статический сервер.

Личные данные и суммы не должны находиться в публичном репозитории. После открытия опубликованного сайта выберите «Данные» → «Загрузить JSON» и укажите подготовленную резервную копию. В ней могут быть плательщики, счета, начисления и оплаты.

Записи сохраняются в `localStorage` конкретного браузера и адреса сайта. Между устройствами они не синхронизируются. После смены адреса GitHub Pages потребуется загрузить JSON на новом адресе. Делайте резервную копию регулярно. Для общей работы с нескольких устройств следующим этапом понадобятся база данных, авторизация и серверный API.
